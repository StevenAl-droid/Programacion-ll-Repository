Descripción

Soy estudiante de la UNTRM, de la carrera profesional de Ingeniería de la Energía y actualmente curso Programación II.

Objetivos

  • Aprender a utilizar Markdown.
  • Conocer la estructura de un archivo README.
  • Crear una página web utilizando HTML.
  • Publicar un proyecto mediante GitHub Pages.

Estructura del proyecto

  • README.md: contiene la documentación del proyecto.
  • index.html: contiene la página web.
