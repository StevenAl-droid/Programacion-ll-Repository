Mi proyecto de introducción

Descripción

Soy estudiante de la Universidad Nacional Toribio Rodríguez de Mendoza (UNTRM), de la carrera profesional de Ingeniería de la Energía y actualmente curso Programación II.

Este proyecto consiste en desarrollar un archivo README y convertir su contenido en una página web utilizando GitHub Pages.

Objetivos

  • Aprender a utilizar Markdown.
  • Conocer la estructura de un archivo README.
  • Crear una página web utilizando HTML.
  • Publicar un proyecto mediante GitHub Pages.

Tecnologías utilizadas

  • Markdown
  • HTML
  • Visual Studio Code
  • GitHub

Estructura del proyecto

  • README.md: documentación del proyecto.
  • index.html: página web del proyecto.
